# Phase 1: Complete the DCGM Hardware Catalog — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

> **Commit policy — read before starting.** `CLAUDE.md` states *"Do not automatically commit until I approve."*
> Every "Commit" step below means: **stage the files, show the diff, and ask for approval.** Do not run
> `git commit` unattended. Commit messages must be brief and carry no AI co-author trailer.

**Goal:** Extend the existing DCGM exporter's field list so every **DCGM-owned** catalog row this hardware can
produce is collected and displayed — proven not to have degraded the fields that already worked.

**Architecture:** Configuration only. The DCGM exporter is never rebuilt, forked or redeployed; its field list
is supplied through a ConfigMap referenced from the GPU Operator's `ClusterPolicy`.

**Tech Stack:** NVIDIA DCGM exporter (existing), NVIDIA GPU Operator `ClusterPolicy` (existing), gpu-burn as
load generator, Grafana, plain numbered YAML.

**Prerequisite:** [Phase 0](2026-08-09-phase-0-backend.md) complete — Prometheus scraping the DCGM exporter,
`scripts/promq.sh` and `scripts/prof-baseline.sh` present and working.

**Scope note:** the nine catalog rows assigned to **NVML** — device utilization and memory, power,
temperature, clocks, throttle reasons, and both per-process rows — are Phase 2's, not this plan's
([00 § 3](../00-decisions.md)). That is why the dashboard here has no memory, power or thermal panel.

## Environment variables used throughout

Set these once per shell. The real values are site-specific and live in the gitignored site note, **not** in
this plan:

```bash
export NS=gpu-monitoring                 # namespace this plan creates
export DCGM_NS=gpu-operator              # namespace where the DCGM exporter already runs
export REGISTRY=<registry host:port>     # from the site note
export CLUSTERPOLICY=<name>              # kubectl get clusterpolicies.nvidia.com -o name
```

> **`ClusterPolicy` is an ambiguous kind name.** Both the NVIDIA GPU Operator
> (`clusterpolicies.nvidia.com`) and Kyverno (`clusterpolicies.kyverno.io`) use it. Always type the fully
> qualified resource name; a bare `kubectl get clusterpolicy` may resolve to the wrong CRD.

```bash
python3 - <<'PY'
import re
def load(p):
    out = {}
    for line in open(p):
        parts = line.split()
        if len(parts) >= 2 and parts[0].startswith("DCGM_FI_PROF_"):
            m = re.search(r'gpu_uuid=([^,}]+)', line)
            try: out[(parts[0], m.group(1) if m else "?")] = float(parts[1])
            except ValueError: pass
    return out

before, after = load("baselines/prof-before.txt"), load("baselines/prof-after.txt")
bad = []
print(f"{'field':<42}{'gpu':<12}{'before':>10}{'after':>10}{'delta%':>9}")
for k in sorted(before):
    b, a = before[k], after.get(k)
    if a is None:
        bad.append(f"{k[0]} DISAPPEARED"); continue
    d = 0.0 if b == 0 else (a - b) / b * 100
    print(f"{k[0]:<42}{k[1][:10]:<12}{b:>10.4f}{a:>10.4f}{d:>8.1f}%")
    if abs(d) > 10:
        bad.append(f"{k[0]} moved {d:.1f}%")
print()
print("REGRESSION:" if bad else "PASS: no field moved more than 10%")
for x in bad: print("  -", x)
PY
```
